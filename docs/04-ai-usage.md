# AI 辅助与贡献记录

## 已发生的辅助

用户提供试卷说明、短视频脚本 Agent 题目和 GitHub 目标账号。Codex 辅助完成需求拆解、架构、代码、测试、合成数据、运行示例和文档，并在本机执行验证。此版本不能描述成候选人“独立手写完成”。未使用多 Agent 并行开发。

`MockProvider` 是人为编写的离线状态模拟器，包含刻意偏长的首稿，供测试修正链路。其动作依据和输出都标为 Mock，不作为真实大模型决策记录。没有使用伪造的模型 API 输出或预设日志冒充 live。

## 候选人个人贡献

已确认：提供业务题目、提交目标及 DeepSeek 接口以便真实模型验证。尚未由候选人确认：亲自修改过的代码、独立验证、对设计取舍的理解与复盘。提交前应根据实际操作更新本段，只记录真实发生的贡献。

建议候选人亲自完成并记录：改变 target_seconds 观察动作差异；在 P01 中加入一条批准事实并检验引用；加入错误素材 ID 确认拒绝；解释为什么修改草稿会使检查失效。这些是建议任务，当前不声称已由候选人完成。

## 验证与数据边界

具体结果见 `03-evaluation.md` 和 `examples/`。测试通过表示对应工程断言成立，不代表模型创作质量、真实配音时长、法律合规或生产可用性。数据为合成数据，不包含真实产品效果、用户资料或密钥。API Key 仅从本机环境读取，不能进入 Git；错误日志不保存服务端响应正文和认证头。

真实模式调用 `deepseek-chat`。自然路径与受控实验分开标注：受控实验种子由测试程序执行本地工具，之后由模型观察结果、选择动作、修订并结束；它们不冒充端到端自然生成。首轮的响应格式失败及第二轮的未触发检索改写记录保留在 `examples/live/attempt-01/`、`attempt-02/`。
