# 需求与验收边界

## 用户与目标

面向有已批准产品资料、需要快速制作短视频的创作者。输入主题、受众、平台、时长上限、风格以及产品资料和品牌规则；输出可编辑的 JSON 和 Markdown 脚本。事实可追溯优先于文案自由度。

## 输入契约

`topic/audience/platform/style` 为非空字符串；`target_seconds` 为 1–600 的有限数值，表示**上限**，不是必须填满的配音长度。缺少任一关键项不能开始业务工具调用。平台是创作上下文，不代表已执行该平台的最新政策审查。

素材文件含唯一 `id`、`product`、`tags`、`facts` 和 `provenance`；品牌规则含禁用词、已批准中性文案、允许的画面描述。资料可为空，此时应询问补充而非生成事实。示例资料完全合成，P01 只含“支持字幕”，不含自动识别、免费、速度或效果数据。

## 输出契约

交付包含标题、分镜画面、旁白/字幕片段、每镜起止时间、预计总时长、逐镜来源 ID、来源原文、检查结果、风险、状态和完整工具 Trace。`script` 只在 completed 时提供，失败草稿单列 `draft`，避免误当成已验收内容。

状态：`completed` 已通过、`needs_input` 待补充、`failed` 明确失败、`incomplete` 步数耗尽。所有模式都会标注模型/模拟器名称。

## 必须验收点

| 场景 | 预期行为 | 验证入口 |
|---|---|---|
| 正常生成 | 检索、生成、估时、校验、交付 | normal |
| 缺关键信息 | 请求缺失字段，无业务工具调用 | missing_info |
| 无素材 | 改写查询或请求补充，不编造事实 | no_materials |
| 工具失败 | 观察错误后恢复或明确失败 | tool_failure |
| 超时长 | 根据估时结果压缩并重检，或说明无法满足 | over_duration / impossible_duration |
| 改变输入 | 60 秒和 30 秒采用不同下一步动作 | normal vs over_duration |
| 有限执行 | 步数耗尽返回 incomplete | step_limit |
| 不支持的事实 | 80% 等虚构结论被拒绝 | tests/test_agent.py |

CLI 为正式运行入口；不包含视频合成、真实配音、线上服务或多 Agent，这些并非必需验收点。离线 Mock 验收只覆盖工程链路，真实模型决策验收须另行运行 live 并审查 Trace。
